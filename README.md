# Relix

**Relix** is a CLI tool designed to simplify and automate software release workflows.

It aims to provide a consistent release process across Git repositories and CI/CD platforms, from release preparation to versioning, changelog generation, and tagging.

## Status

🚧 Work in progress. Relix is under active development.

## Goals

- Simplify release preparation and finalization.
- Support configurable release workflows.
- Remain independent of any specific Git hosting or CI/CD platform.
- Provide a predictable, reproducible, and easy-to-use CLI.
